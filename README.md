# University Management System (Java)

The **University Management System** is a Java-based application designed to manage and organize university-related information such as students, faculties, courses, and departments. The system helps streamline administrative tasks and improves efficiency in handling academic records.

##  Objective
To provide an easy-to-use management solution that can:
- Store student and faculty details
- Manage courses and enrollments
- Generate reports and maintain academic records

## Features
- Add, view, update, and delete student records
- Manage faculty details
- Handle course and department information
- Student course enrollment
- Display organized report data

## Technologies Used
| Component     | Technology |
|---------------|------------|
| Programming   | Java       |
| Database  | MySQL / SQLite 
| IDE           | IntelliJ |
